# Refleksi Materi Technopreneurship

Website interaktif yang merangkum materi perkuliahan **Technopreneurship** ke dalam tujuh topik pembelajaran dan satu bagian narasi lengkap. Halaman dibuat dalam format HTML dengan tampilan bertema **Aircraft Maintenance** menggunakan nuansa gradasi hijau.

## Preview

Website menampilkan:
- Header dengan latar visual hanggar pesawat.
- Navigasi berbasis tab untuk berpindah antar materi.
- Gambar ilustratif bertema penerbangan dan aircraft maintenance pada setiap tab.
- Ringkasan poin utama dan narasi refleksi untuk setiap topik.
- Bagian **Narasi Lengkap** untuk membaca keseluruhan refleksi.
- Indikator progres dan penanda materi yang telah dibuka/diselesaikan.
- Fitur pencarian teks pada materi.
- Tampilan responsif untuk desktop dan perangkat mobile.

## Materi yang Dibahas

| No. | Topik | Fokus Pembahasan |
|---|---|---|
| 1 | Concept | Konsep technopreneurship, peluang, inovasi, penciptaan nilai, dan pola pikir *Be, Do, Have*. |
| 2 | Character | Karakter technopreneur, tujuan, kreativitas, adaptasi, dan keberanian mengambil risiko. |
| 3 | Leadership | *Self-leadership*, kesadaran diri, tanggung jawab, visi, dan pengembangan tim. |
| 4 | Communication & Motivation | Komunikasi efektif, kemampuan mendengarkan, pemahaman audiens, dan motivasi. |
| 5 | FSQ – Financial Literacy | Literasi keuangan, pengelolaan arus kas, aset, liabilitas, dan keputusan finansial. |
| 6 | Business Model & Proposal | Model bisnis, *Value Proposition*, dan sembilan elemen *Business Model Canvas*. |
| 7 | Exponential Mindset, Thinking, Creativity and Innovation | Pola pikir eksponensial, eksperimen, kolaborasi, kreativitas, dan inovasi. |

## Teknologi

Proyek ini dibuat menggunakan:
- **HTML5** — struktur halaman.
- **CSS3** — tata letak, warna gradasi hijau, animasi, dan desain responsif.
- **JavaScript** — interaksi tab, navigasi materi, progres, dan pencarian.
- **Google Fonts** — tipografi halaman.
- **Unsplash** — gambar ilustratif yang digunakan sebagai visual pendukung.

## Cara Menjalankan

1. Unduh atau clone repository ini.
2. Pastikan file HTML utama tersedia di folder proyek.
3. Buka file HTML menggunakan browser seperti Google Chrome, Microsoft Edge, atau Firefox.

Tidak diperlukan instalasi package atau proses build karena proyek berjalan langsung di browser.

## Publikasi Menggunakan GitHub Pages

1. Buat repository baru di GitHub.
2. Unggah file HTML proyek ke repository.
3. Ubah nama file utama menjadi `index.html` agar mudah dikenali sebagai halaman utama GitHub Pages.
4. Buka **Settings → Pages** pada repository.
5. Pada bagian **Build and deployment**, pilih **Deploy from a branch**.
6. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
7. Tunggu proses publikasi selesai. GitHub akan menampilkan alamat website pada halaman pengaturan Pages.

## Catatan
